# Adega do Rick - Plataforma de E-commerce e Delivery

Este projeto consiste no desenvolvimento de um sistema web para a **Adega do Rick**, visando a modernização do atendimento, gestão de pedidos e rastreamento de entregas em tempo real.

## 🚀 Tecnologias Utilizadas
* **Front-end:** HTML5, CSS3 e JavaScript.
* **Maps:** Leaflet.js + OpenStreetMap API.
* **Back-end/Banco de Dados:** MySQL.
* **Versionamento:** Git.

## 📋 Levantamento de Requisitos (Etapa 1)

### Requisitos Funcionais (O que o sistema faz)
- [ ] **RF01:** Catálogo de produtos com categorias e preços.
- [ ] **RF02:** Aba de produtos em destaque/desconto.
- [ ] **RF03:** Carrinho de compras funcional.
- [ ] **RF04:** Finalização de pedido com tempo estimado de entrega.
- [ ] **RF05:** Sistema de rastreamento de rota do entregador (Leaflet.js).
- [ ] **RF06:** Painel administrativo para gestão de pedidos.

### Requisitos Não Funcionais (Qualidade)
- **RNF01:** Interface totalmente responsiva (Mobile-First).
- **RNF02:** Geolocalização em tempo real com atualização a cada 30 segundos.
- **RNF03:** Persistência de dados segura em MySQL.
